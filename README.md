# DROPZONE

Симулятор открытия кейсов Counter-Strike. Десять авторских кейсов по 30 предметов, 108 скинов, анимированная рулетка и мягкие звуки прокрутки. Регистрация не нужна: баланс в виртуальных долларах можно задавать вручную.

Открывай один, три или пять кейсов, забирай предметы в инвентарь и продавай их за виртуальные доллары. Доступны быстрый режим и отключение звука. Баланс и коллекция сохраняются в текущем браузере.

## Запуск

Нужен Node.js 22 или новее. Установка зависимостей не требуется.

```sh
npm run dev
```

Сайт откроется на `http://127.0.0.1:5173`.

```sh
npm test
npm run build
npm run bench
```

Готовые статические файлы находятся в `dist/`. Их можно разместить на CDN или любом статическом хостинге. Для проверки готовой сборки: `node scripts/serve.mjs --dist`.

Локальный сервер принимает подключения только с этого компьютера и отдаёт только файлы интерфейса и ресурсы. Для внешнего размещения следует раздавать содержимое `dist/`, а не каталог репозитория. Локальный сервер предназначен для проверки; его результаты не подтверждают пропускную способность при публикации.

## Данные

Приложение не запрашивает имя, почту или другие контактные данные. Аналитики, отправки сохранений и внешних запросов при открытии кейсов нет. В браузере сохраняются виртуальный баланс, инвентарь, недавние открытия и настройки звука. На общем компьютере этим сохранением пользуются все, кто открывает сайт в том же профиле браузера.

Изображения и шрифты загружаются с адреса сайта. Источник цены открывается только при нажатии на ссылку и получает отдельное обращение посетителя. При внешнем размещении сервер получает IP для соединения, а сохранение журналов доступа зависит от настроек хостинга. Локальный запуск не публикует сайт в интернете.

## Устройство

JavaScript без сторонних зависимостей. Суммы хранятся целыми числами в сотых долях доллара. Выбор предметов использует `crypto.getRandomValues` с устранением смещения. Вероятность каждого предмета показана в кейсе.

Списание и выдача предметов сохраняются одной операцией до начала анимации. Перезагрузка не теряет дроп. Изменения между вкладками сериализуются через Web Locks; при его отсутствии используется транзакция IndexedDB. Для общих вкладок нужен один origin и HTTPS, кроме локального запуска.

Инвентарь вмещает 2000 предметов, отображение загружается порциями. Повторная продажа не начисляет баланс повторно. При ошибке записи изменение не подтверждается. Если браузер запрещает хранилище, доступен временный сеанс без сохранения после закрытия вкладки.

## Нагрузка

Открытие, баланс, звук и инвентарь работают в браузере. На сервере нет вычислений открытия, базы данных и сессий. Ресурсы локальные, изображения в WebP, шрифты в WOFF2. Сборка присваивает ресурсам адреса по хешу содержимого и формирует правила долгого кеширования.

Количество одновременных посетителей зависит от выбранного CDN и его тарифа. Локальный `bench` измеряет только выбор предметов; он не подтверждает пропускную способность хостинга.

## Цены и вероятности

Для всех 108 предметов указана рыночная оценка в USD для конкретного состояния износа и обычной версии без StatTrak. Karambit Doppler Ruby оценён отдельно от остальных фаз. Источник — минимальные цены предложений продажи на торговых площадках, собранные [CSGOSKINS.GG](https://csgoskins.gg). Цена на карточке ведёт к источнику; исходные значения, площадка, дата проверки и возраст данных сохранены в `data/skin-prices.json`.

Это снимок доступных предложений, а не поток текущих котировок. Реальная цена сделки зависит от площадки, float, паттерна и доступности конкретного лота. Перед обновлением каталога нужно сверить тот же износ и разновидность.

В каждом кейсе вероятность уменьшается с ростом цены предмета. Цена открытия рассчитывается по содержимому с округлением вверх до $0.10, чтобы средний возврат не превышал 65%. Вероятность получить предмет не дешевле одного открытия составляет не более 15%; для серий ×3 и ×5 вероятность окупить всю серию отличается.
